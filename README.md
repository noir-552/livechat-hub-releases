# LiveChat Hub — APK releases

This repository contains **only Android APK releases** of LiveChat Hub. The source code is private and is not published here.

Download the latest APK from [Releases](https://github.com/noir-552/livechat-hub-releases/releases). Builds marked *Pre-release* are test builds.

The app checks this repository for updates on start. It installs only after you tap **Unduh & pasang** and confirm in Android. Downloads are checked against the SHA-256 digest GitHub publishes for the asset, and must be the same app package with a newer version; Android also requires the same signing key.
